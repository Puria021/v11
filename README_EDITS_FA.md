# تغییرات تجمیعی MyArticleManager

این بسته شامل سورس Tauri/React و تغییرات یکپارچه پیشنهادی است. خروجی Windows installer نیست.

- تست واقعی API تصاویر (ممکن است هزینه داشته باشد)
- تنظیم تعداد مقالات هر پروژه و هر کمپین: ۱ تا ۲۰۰
- دکمه رفرش مراحل ۵ و ۶ کمپین
- مخفی شدن به System Tray و ادامه پردازش در بک‌اند
- تولید تا ۱۰ تصویر برای مقاله، تصویر اول شاخص؛ تصاویر بعدی هر N پاراگراف در وردپرس درج می‌شوند
- شماره تماس پروژه و CTA با متغیرهای `{{phone}}` و `{{phone_link}}` در قالب
- بازنشانی اطلاعات با عبارت اجباری RESET ALL و تأیید دوم (پیش از عملیات پشتیبان تهیه شود)
- تنظیم FAQPage JSON-LD در قالب و هنگام آپلود وردپرس

**محدودیت اعتبارسنجی:** در این محیط ابزار Rust/Cargo و اجزای لازم npm به‌طور کامل موجود نبودند؛ بنابراین تست Rust، TypeScript و ساخت installer ویندوز انجام نشده است. پیش از انتشار روی ویندوز از GitHub Actions پروژه (Build Windows installer) برای `npm ci`, `npm run build`, `cargo test`, `npm run tauri build` استفاده کنید و مشکلات احتمالی را برطرف کنید.

**احتیاط:** بک‌آپ اطلاعات موجود را بگیرید. هزینه تولید تصاویر ممکن است با تعداد تصاویر افزایش یابد. FAQ schema نمایش rich result در گوگل را تضمین نمی‌کند.
