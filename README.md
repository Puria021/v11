# MyArticleManager

نرم‌افزار دسکتاپ ویندوز (Tauri 2 + React + SQLite) برای مدیریت چند سایت WordPress و تولید مقاله با AI.

**وضعیت:** کد هر ۵ مرحله نوشته و با تست خودکار بررسی شده است (۵۱ تست). **هنوز هیچ نصب‌کننده‌ی ویندوز ساخته و روی ویندوز اجرا نشده** — بخش «ساخت خروجی ویندوز» را ببینید.
معماری و قراردادها: `docs/ARCHITECTURE.md` و `docs/COMMANDS.md`.

## امکانات فعلی
- ساخت/ویرایش/حذف پروژه (با تأیید حذف)؛ هر پروژه یک سایت WordPress مستقل
- اتصال WordPress با Application Password (ذخیره در Windows Credential Manager، نه در دیتابیس)
- Test Connection، دریافت دسته‌ها، برچسب‌ها، نویسندگان و Post Typeها
- Proxy اختیاری برای هر اتصال
- نمایش وضعیت اینترنت؛ UI فارسی/RTL با فونت داخلی (کار در حالت آفلاین)
- داده‌ها در `%APPDATA%\com.myarticlemanager.app\data\app.db`

## امکانات مرحله ۳
- ارائه‌دهنده‌ی AI: OpenAI و هر API سازگار با OpenAI (Base URL + کلید + مدل + Proxy)؛ Anthropic و Gemini در مرحله ۴
- کمپین و ویزارد ۴ مرحله‌ای (ذخیره‌ی خودکار مرحله)
- کلمات کلیدی: ورود CSV (حجم/رقابت/CPC/روند/مرتبط از داده‌ی واقعی شما)، افزودن دستی، پیشنهاد AI **بدون هیچ عدد جستجو**؛ جدول با جستجو، مرتب‌سازی، فیلتر منبع و انتخاب
- تولید دقیقاً ۶۰ کلمه‌ی ثانویه‌ی یکتا؛ اگر کمتر پیدا شود کمبود اعلام می‌شود و چیزی ساختگی اضافه نمی‌شود
- هشدار شباهت (Cannibalization) و برچسب هدف جستجو (قاعده‌محور، نه قطعی)
- تولید ۶۰ عنوان، تأیید/ویرایش دستی/عنوان جایگزین/رد، شمارنده‌ی ۶۰/x
- DataForSEO و سایر Keyword Providerهای API هنوز اضافه نشده‌اند

## امکانات مرحله ۴
- **ارائه‌دهندگان AI:** OpenAI، هر API سازگار با OpenAI، Anthropic (Claude) و Google Gemini؛ محدودیت درخواست در دقیقه و حداکثر همزمانی برای هر ارائه‌دهنده
- **ارائه‌دهنده‌ی تصویر:** سرویس‌های سازگار با OpenAI Images (پاسخ `b64_json` یا `url`)
- **قالب مقاله:** دستورالعمل، ساختار، قوانین سئو، لحن، حداقل/حداکثر کلمه، FAQ، CTA، سبک تصویر، Placeholderها؛ یک قالب پیش‌فرض فارسی آماده است
- **صف محلی (SQLite):** همزمانی قابل تنظیم، Backoff نمایی، Pause/Resume/Cancel، بازیابی خودکار پس از بسته شدن برنامه
- **تولید مقاله:** خروجی JSON ساختاریافته ← پاک‌سازی HTML ← کنترل کیفیت (کلمه‌ی کلیدی، ساختار H2/H3، طول، FAQ، محتوای تکراری) ← تلاش مجدد با بازخورد؛ عنوان تأییدشده‌ی شما همیشه عنوان نهایی است
- **پیشرفت زنده** از طریق Eventهای Tauri، جدول وضعیت مقالات، مشاهده‌ی متن/تصویر، تلاش مجدد برای هر مرحله
- در این نسخه فقط یک تصویر شاخص برای هر مقاله پشتیبانی می‌شود؛ اعلان ویندوز و آپلود به وردپرس در مرحله ۵

## امکانات مرحله ۵
- **ساخت Draft در وردپرس:** آپلود تصویر شاخص (با Title/Alt)، ساخت برچسب‌های ناموجود، دسته‌ی هر مقاله یا دسته‌ی پیش‌فرض پروژه، FAQ در انتهای متن (و JSON-LD اختیاری از قالب)؛ وضعیت نوشته همیشه `draft` است
- **جلوگیری از آپلود تکراری:** هر مقاله حداکثر یک رکورد وردپرس دارد؛ تلاش دوباره `DUPLICATE_BLOCKED` می‌دهد. اگر پاسخ ساخت نوشته گم شود، در تلاش بعدی نوشته‌ی موجود با همان slug پیدا و «تصاحب» می‌شود. تصویر دوباره آپلود نمی‌شود
- **ویرایشگر مقاله:** ویرایش HTML با نوار ابزار (H2/H3، پررنگ، کج، لیست، جدول، لینک، نقل‌قول، کد)، ویرایش FAQ/Slug/Meta، پیش‌نمایش شبیه مقاله‌ی واقعی با HTML پاک‌سازی‌شده توسط Rust، کنترل نسخه (جلوگیری از بازنویسی ناخواسته)
- **دسته و برچسب** برای هر مقاله، قبل از آپلود
- **صفحه‌ی لاگ:** فیلتر پروژه/کمپین/مقاله/سطح/وضعیت/عملیات/تاریخ/متن، صفحه‌بندی، خروجی CSV
- **Backup / Import (.aiproj):** پیش‌نمایش قبل از ورود، حالت «حفظ موجودها» یا «جایگزینی»؛ کلیدها و رمزها هرگز صادر نمی‌شوند
- **اعلان ویندوز** پایان تولید یا بروز خطا
- **حذف برنامه (Uninstall):** نصب‌کننده‌ی NSIS تائوری گزینه‌ی «Delete the application data» دارد که به‌صورت پیش‌فرض خاموش است (داده‌ها حذف نمی‌شوند)

## محدودیت‌های شناخته‌شده
- Meta Title / Description به Yoast یا Rank Math ارسال نمی‌شود (نیاز به ثبت فیلدهای meta در سایت دارد)
- Internal Linking، Schedule انتشار، چند تصویر برای هر مقاله، DataForSEO و بروزرسانی خودکار پیاده‌سازی نشده‌اند
- ذخیره‌ی رمز در Windows Credential Manager و گفتگوهای انتخاب فایل / اعلان فقط روی ویندوز قابل بررسی‌اند

## ساخت خروجی ویندوز

### روش ۱ — GitHub Actions (بدون نصب چیزی روی سیستم)
۱. پروژه را در یک مخزن GitHub قرار دهید.
۲. تب Actions ← «Build Windows installer» ← Run workflow.
۳. بعد از پایان، فایل‌های `.exe` و `.msi` را از Artifacts دانلود کنید.

### روش ۲ — روی خود ویندوز
نیازمندی‌ها (فقط برای ساخت، نه برای کاربر نهایی): Node.js 20+، Rust (rustup)، Visual Studio Build Tools (Desktop development with C++)، WebView2 (روی ویندوز ۱۰/۱۱ معمولاً نصب است).

```
npm install
npm run tauri dev      # اجرای توسعه
npm run tauri build    # خروجی در src-tauri/target/release/bundle/
```

## تست
```
cd src-tauri
cargo test
```
تست‌ها با یک WordPress ساختگی (wiremock) اجرا می‌شوند و به سایت واقعی نیاز ندارند.
